# 俄罗斯方块

FoloToy AI Passport 上的单机俄罗斯方块。棋盘 10 列 × 20 行，采用 7-bag 随机序列，界面为中文，最高分、单存档、声音和音量保存在 NVS 中。

## 开始游戏

开机进入开始界面，用上/下键选择、确定键确认：

| 选项 | 说明 |
| --- | --- |
| 开始新游戏 | 立即开始一局，并覆盖旧存档 |
| 继续游戏 | 恢复上次存档，下方显示存档的分数与行数；没有存档时显示「暂无存档」且不可选择 |
| 设置 | 调整声音与音量，长按确定返回 |

游戏内长按上键进入暂停菜单：继续游戏 / 设置 / 退出游戏。选择「退出游戏」会保存当前进度并回到开始界面；在游戏结束界面可以选择「再来一局」或「返回菜单」。

## 按键

设备只有三个按键，游戏内上/下键用于左右移动：

| 场景 | 操作 | 动作 |
| --- | --- | --- |
| 开始、暂停、结束菜单 | 上/下短按 | 切换选项 |
| | 确定短按 | 确认 |
| 游戏中 | 上短按 | 向左移动一格 |
| | 下短按 | 向右移动一格 |
| | 确定短按 | 顺时针旋转（带踢墙） |
| | 按住确定 | 加速下落，松手恢复正常速度 |
| | 长按上键 | 暂停并保存 |
| 已暂停 | 上/下短按 | 选择菜单项 |
| | 长按上键 | 直接继续游戏 |

短按确定是在松手时旋转；按住约 0.5 秒后进入加速下落，此时不会再旋转。加速下落期间松手立即恢复正常下落速度。

## 游戏规则

- 方块从棋盘顶部生成，落地或碰到已有方块后锁定；锁定后检查是否有整行填满。
- 填满的行会消除，上方的方块整体下移，并累计消除行数。
- 新方块在出生点被挡住时游戏结束。
- 方块序列使用 7-bag：每 7 个方块包含全部 7 种形状各一次，不会长时间缺少某种方块。
- 一次消除 4 行会显示庆祝贴纸并播放专属音效；如果这次消行同时触发难度升级，则优先显示难度提示。

### 计分

| 一次消除行数 | 得分 |
| --- | --- |
| 1 行 | 100 × 当前难度 |
| 2 行 | 300 × 当前难度 |
| 3 行 | 500 × 当前难度 |
| 4 行及以上 | 800 × 当前难度（按四行封顶） |

难度取**消行前**的数值。游戏结束时如果分数超过历史最高分，会写入最高分并显示「新纪录！」。

## 难度升级

难度从 1 开始，**每累计消除 30 行提升一档**：

```
难度 = 累计消除行数 / 30 + 1
```

升级时会出现以下变化：

- **速度加快。** 每档下落间隔减少 80 ms，最低 140 ms：

  | 难度 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 及以上 |
  | --- | --- | --- | --- | --- | --- | --- | --- | --- |
  | 下落间隔 | 700 ms | 620 ms | 540 ms | 460 ms | 380 ms | 300 ms | 220 ms | 140 ms |

- **关闭落点预览。** 难度 1 会在当前方块下方显示落点轮廓，难度 2 起不再显示。
- **新增障碍行。** 从难度 2 起，每次升级会清完行后在棋盘底部追加一整行方块，只留一个随机缺口，原有方块整体上移。由于障碍行只在消行后追加，顶行一定是空的，不会因为加障碍直接顶死。
- **文字提示。** 右侧信息栏会显示约 2.5 秒的提示卡片：

  ```
  难度提升！
  速度加快
  关闭落点提示
  新增障碍行
  ```

  同时播放升级音效。提示期间游戏不会暂停。

难度不单独存档：读档时根据累计行数重新推导，旧存档不会带着与行数不一致的难度进入游戏。

## 存档与记录

- 游戏中每 8 秒自动存档一次；暂停、退出到开始界面时也会立即保存。
- 只有一份存档，包含棋盘、当前方块与下一个方块、随机序列、分数、行数和难度；新开一局会覆盖旧存档。
- 游戏结束后自动删除存档，避免「继续游戏」恢复到已经结束的局面。
- 存档带 CRC 与字段校验，损坏或不兼容的数据会被拒绝，不会写入异常盘面。
- 最高分、声音开关和音量分别保存在 NVS，重新开机后仍然有效。

## 设置

| 操作 | 说明 |
| --- | --- |
| 确定短按 | 开关声音 |
| 上/下短按 | 调节音量，每次 5%，范围 0–100；仅在声音开启时可用 |
| 长按确定 | 返回上一层（开始界面或暂停界面） |

默认声音开启、音量 55%。关闭声音后音量条变暗，但数值仍保留，重新开启声音时恢复。

## 界面说明

- 顶部显示标题和电量百分比。
- 左侧是棋盘；右侧从上到下显示下一个方块、分数、行数、难度、最高分，以及暂停提示。
- 底部显示操作提示；按键不可用时改为显示错误提示。
- 难度升级提示和四行消除庆祝贴纸都显示在右侧信息栏，不遮挡棋盘。
